조회 버튼을 누르면 선택한 시간창에 유효한 NOTAM이 표시됩니다.
실시간 기준
조회 후 반경 내 ADS-B 항공기가 표시됩니다.

NOTAM 원문 붙여넣기

AIM Korea(aim.koca.go.kr) 등에서 복사한 ICAO 형식 NOTAM을 여러 건 그대로 붙여넣으세요. 중계 서버 없이도 시간·지역 필터와 지도 표시가 됩니다.

설정

비워 두면 NOTAM은 붙여넣기만, 항적은 공개 API 직접 호출을 시도합니다(브라우저 CORS 정책상 실패할 수 있음).
